- [x] 新建 Java + Android 平台控件 App，导入固定 AAR 快照；无源码模块、termlib 或 rootfs 预置依赖。
- [ ] App 进程内验证初始化、真实 Alpine 下载/安装、exec 参数/退出状态、事件序列/进度/错误与项目持久化。
- [ ] 使用 AAR 的 PTY JNI 验证持续输入输出、TTY、resize、退出，并提供手动交互界面。

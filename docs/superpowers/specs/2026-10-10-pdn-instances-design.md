# PDN named instances

Allow `pdn install DISTRO --name INSTANCE` with the existing mutually exclusive archive/mirror options in either order. Omitted name retains the canonical distro name. Instance names follow existing ASCII rootfs naming rules, maximum 128 bytes; conflict detection remains case-insensitive. Login, exec, remove, config and backup already select by rootfs name and require no new execution mode.

Store versioned bounded instance metadata inside each new rootfs, before atomic publication. Metadata contains a randomly generated 128-bit hex ID, instance name, canonical distro, distro version, aarch64 architecture, source kind (archive/mirror/restore), optional source URL, pinned archive SHA256 and Unix creation timestamp. Use a private line-based file `.pdn-instance` with version=1 and fixed key=value fields and emit JSON only through public list output. Reject malformed/nonregular/symlink metadata in structured queries instead of guessing. Legacy rootfs directories remain usable and list with metadata=null; querying never modifies them.

`list --json` retains protocol version 1 and existing name/rootfs fields and adds optional `instance` object. Object example: {"version":1,"id":"0123456789abcdef0123456789abcdef","name":"ai-python","distro":"alpine","distro_version":"3.24.2","architecture":"aarch64","source":"archive","source_url":null,"sha256":"64 lowercase hex digits","created_at":1791620000}. All structured rows are prepared before stdout is emitted, avoiding partial JSON on failure.

Backup preserves valid metadata as provenance; restore generates a fresh ID/name/timestamp before publication and marks source=restore while retaining known distro/version/digest/URL. Restoring legacy archives creates metadata with distro/version/sha256/URL unknown (null JSON). Installation errors, cancellation, publication conflict and metadata failures leave no published instance. Metadata is descriptive and editable by the guest, not a security authority.

AAR preserves existing install overloads. Add installAs(distro, instanceName, mirror?, archive?) usable from Kotlin/Java and getters for optional installed instance metadata. Old installed JSON and available catalog rows remain supported. Direct SO example gets a corresponding argument-array helper. Validate two same-distro instances, independent data, case-insensitive conflicts, malformed metadata, legacy rootfs, restore ID regeneration and API contract.

Version 0.6.12. Native regression and touched coverage >=80%, SDK tests and coverage >=80%, native/AAR matching, four Debug/R8 AAR/SO real-device suites and MT checks where available. CI creates drafts; publish after matching candidate payload acceptance. Clone/rename, OCI and filesystem recovery remain out of scope.

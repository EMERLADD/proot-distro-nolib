# PDN clone and rename

Add CLI `clone SOURCE TARGET` and `rename SOURCE TARGET`, and matching Java/Kotlin ProcessBuilder methods. Preserve existing operations and protocol v1. Source lookup remains compatible with legacy names; targets use the current 128-character instance-name rules. Name conflicts are case insensitive; exact same actual name is rejected, case-only rename is supported.

Clone uses the existing bounded archive traversal and extraction inside an owned hidden staging directory, with the global install lock and exclusive source rootfs lock held throughout. Publish with NOREPLACE after files, config and metadata are complete. Generate a fresh ID/time and source=clone, retaining known distro/version/digest/download URL; legacy source provenance may remain null. Preserve validated configuration, rewriting only bind host paths rooted inside the source. External binds remain shared. Runtime directories, temporary files and unsupported special files follow existing backup rules. Own-root ordinary absolute symlinks normalize to guest paths; link2symlink backing links rebase to the final target rootfs.

Rename moves the directory instead of copying the rootfs. Plan bounded, no-follow link traversal while locked; rewrite only symlink targets rooted at the source host path, including link2symlink backing targets. Guest absolute, relative and unrelated external symlinks remain unchanged. Migrate validated bind host paths within the source root, preserving environment strings, guest users and working directories. Preserve instance ID, creation time and provenance while updating its name. Legacy rootfs may retain absent metadata.

Journal original link/config/metadata values for rollback on ordinary failures and SIGINT/SIGTERM before directory publication. Refuse symlink sources, malformed metadata, unsafe config, active sessions and conflicting destinations without changing existing instances. Publication uses NOREPLACE; cancellation cannot turn a completed publication into a reported rollback. Do not claim crash consistency after SIGKILL or power loss; durable interrupted-operation recovery remains a separate task.

Do not rewrite arbitrary guest file contents or another instance's links/config. No OCI, project-directory copying or GUI alias controls. Validate native regression and >=80% touched coverage, SDK tests, MT and Android shell, and AAR/direct SO Debug plus R8 Release with matching native bytes before publication. Deliver version 0.6.13 and preserve historical artifacts.

# v0.3.0：Alpine 安装

## 范围与验收

- `pdn install alpine` 从清华 TUNA 下载 Alpine 3.24.2 aarch64 minirootfs。
- 命令和发行版名称忽略 ASCII 大小写；路径保留原样。
- `--archive PATH` 可使用本地同版本官方压缩包，仍校验固定大小及 SHA256。
- 目标目录沿用 PDN_ROOTFS_DIR 或 HOME 下的默认目录，名称固定为 alpine。
- 下载必须通过 HTTPS 证书和主机名验证；校验失败不得解压。
- 已有 alpine（包括大小写变体）不得覆盖；同目录安装使用排他锁。
- 临时目录中解压成功并完成初始化后才发布为 alpine；通常失败、SIGINT、SIGTERM 清理临时目录。
- SIGKILL、断电留下的隐藏临时目录不视为安装完成，也不阻止后续安装。
- 解压保留普通权限和符号链接，拒绝目录越界、符号链接穿越及特殊设备文件。
- 配置同版本清华 apk 软件源和基础 DNS；真实测试登录、apk update 和包安装。

## 实现

现有原生入口调用独立 C 安装模块。静态链接 curl 8.22.0、Mbed TLS 3.6.7、
libarchive 3.8.9、zlib 1.3.2，不调用宿主下载器或解压程序。
依赖从官方 HTTPS 地址下载并校验固定摘要，仅写入 build 目录，不修改 vendor。
Android 系统证书目录用于 TLS，PDN_CA_BUNDLE 可显式指定 PEM 信任文件。
临时目录位于目标父目录，完成后以目录重命名发布；不会移动或修改已有发行版。
依赖库许可证随构建产物提供。

## 验证

最小压缩包测试安装事务、失败清理、并发锁、目录/链接边界和配置写入。
本地 HTTPS 测试验证证书、重定向、HTTP 错误、下载限制和中断。
真实 Alpine 镜像验证固定摘要、清华下载、Linux 登录和包管理。
保留引擎、现有登录与列表回归测试，新增模块覆盖率至少 80%。

自动测速、断点续传、其他发行版和通用任意压缩包导入不属于本版。

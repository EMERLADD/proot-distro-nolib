# v0.3.1：Alpine 国内外下载源

范围：Alpine 多源和失败切换，不增加其他发行版、测速或断点续传。

- 固定顺序：清华、中科大、南大、Alpine 官方 CDN、dotsrc。
- 所有来源使用同一 Alpine 3.24.2 ARM64 文件、固定大小和 SHA256。
- 网络、HTTP、大小、校验失败时丢弃本次下载，依次尝试下一源。
- 中断直接停止；所有来源失败后不发布 rootfs，清理本次临时文件。
- `pdn mirrors` 显示名称和地址；`install alpine --mirror NAME` 仅使用指定源。
- 命令、参数和镜像名称忽略 ASCII 大小写，原有路径参数保留大小写。
- 在线安装的 apk 仓库跟随成功下载源；本地压缩包安装沿用清华配置。
- 不修改已经安装的发行版及其软件源。

验证：候选源同版本摘要和小范围下载；本地 HTTPS 模拟首源 HTTP 错误、
截断、超限、校验错误、次源成功、全部失败、手动选源及取消；真实国内外源安装。

候选来源：https://mirrors.alpinelinux.org/
